# A1 출력 보드 (B조 · Tea Canvas)
- `TEA_CANVAS_A1_B.pdf` — 인쇄용 A1 (594×841mm, 한 장). 글자·도식은 벡터, 화면은 약 300dpi
- `board.html` — 보드 원본 (920px 기준으로 짜고 인쇄할 때 A1 크기로 키운다). 글을 고치려면 이 파일을 고친 뒤 `node exhibit/a1/pdf.js`
- `s1~s5-*.png` — 화면 디자인 칸에 들어간 실제 앱 화면 (393×852, 3배 해상도). `shots.js`로 다시 찍을 수 있다
- 구조(IA·플로우·와이어프레임)는 board.html 안의 SVG 도식
- 팀원 이름 칸은 자리 표시만 두었다
