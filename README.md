# TEA CANVAS

마시면서 내 말로 남긴 향과 맛이 수채화 찻방울로 번지는 차 기록 앱의 프로토타입이에요.
'사용자경험과인터페이스디자인' 과제전용으로 만들었고, 실제로 쓸 수 있는 수준을 목표로 했어요.

- **앱 주소:** https://teacanvas.github.io/TEA_CANVAS_prototype_v6.html
- 휴대폰에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있어요.
- 큰 화면(전시용 모니터)에서 열면 가운데에 휴대폰 모양으로 나와요.

## 한 잔을 기록하는 흐름
1. **Home**에서 아래로 흘러가는 물감 중 하나를 골라(안 고르면 무작위 색) 위쪽 화면을 터치해요. 그 색이 번지며 풍미 이름이 뜨고 대화로 넘어가요.
2. AI와 대화하며 기록해요. 순서는 차 이름(사진으로도 찾을 수 있음) → 우림 가이드와 타이머 → 찻물 색(슬라이더) → 향 → 맛 → 마시며 이야기 → 여운이에요. 종류는 이름에서 분명하면 묻지 않고, 모를 때만 물어요.
   - 점선 말풍선은 예시 문장이에요. 누르면 바로 보내져서, 예시만 눌러도 끝까지 갈 수 있어요(전시용).
   - 하던 기록은 1분 안에 돌아오면 이어할지 묻고, 1분이 지나면 지우고 새로 시작해요.
3. **기록 마치고 정리하기**를 누르면 내 표현이 풍미 색으로 스며들며 찻방울이 완성돼요.
4. 비교 화면에서 전문가 설명, 공통점과 차이점, AI 해석, 나만의 표현을 봐요.
5. **캔버스에 찍기**로 마무리해요. 가로는 향(오른쪽일수록 좋음), 세로는 맛(위쪽일수록 좋음)이고, 길게 누를수록 진하게 찍혀요. 마지막으로 별점, 한 줄 코멘트, 사진을 남겨요.

## 화면 구성
- **Home:** 캔버스 종이 위 '화면을 터치하여 기록을 시작하세요'와 흘러가는 물감 줄. 번짐은 WebGL로 그려요(안 되면 그림 겹치기).
- **Canvas › 캔버스:** 모든 기록을 찍은 지도예요.
  - 기간을 고를 수 있어요: 전체 · 1개월 · 3개월 · 올해 · 달력.
  - 방울이 겹칠수록 연하게 그려서 캔버스가 어두워지지 않아요.
  - 맨 아래의 "나의 취향 찻방울"과 추천 차도 이 화면에 있어요.
- **Canvas › 기록:** 기록 목록이에요. 검색, 종류·풍미·기간 필터가 있고, 상세 화면에서 기록을 고치거나 지울 수 있어요.
- **My:** 프로필, 마신 차 종류, 설정이 있어요.
  - 대화 방식: AI 대화 / 자동 대화
  - 목소리: 여성 / 남성
  - 실시간 음성 대화
  - 영어

## AI는 이렇게 동작해요
- **Gemini 무료 플랜**을 써요. 앱은 `ai-worker/worker.js`(Cloudflare Worker)를 거쳐 Gemini에 물어봐요. API 키는 Worker에만 있고 앱 코드에는 없어요.
- **역할 분담:** 대화와 판단은 Gemini가 하고, 앱은 Gemini가 정한 것을 실행만 해요.
  - Gemini에게 주는 것: 앱 설명서, 지금 기록 상태, 지난 기록 요약(최근 30잔, 읽기만 가능)
  - Gemini가 매번 돌려주는 것: 기록할 칸, 지울 칸, 찻방울 풍미, 앱에 하는 요청(색 슬라이더, 가이드, 타이머 등), 다음 단계
- 실시간 음성(Gemini Live)도 같은 규칙과 같은 처리 함수(`flowDecide`)를 써요.
- 무료 한도에 걸리거나 연결이 안 되면, 그 말만 미리 정해 둔 자동 대화로 이어가요. 다음 말부터는 다시 AI를 시도해요.
- 화면 위 표시('AI 대화' / '자동 대화')는 방금 말을 실제로 누가 받았는지 보여줘요.
- 무료 플랜에서는 보낸 내용이 구글 서비스 개선에 쓰일 수 있어요. 개인 정보는 적지 않게 안내해 주세요.

## 숨은 단축키 (전시·시연용)
- `Ctrl + Alt + D`: 개발자 패널을 열어요. 모든 화면으로 바로 갈 수 있어요.
- `Ctrl + Alt + Shift + 0`: 관람객 기록을 모두 지우고 예시 기록만 남겨요.

## 고칠 때 지켜 주세요
1. 앱은 `TEA_CANVAS_prototype_v6.html` 한 파일이에요. **한 줄 코드 중간에 `//` 주석을 넣지 마세요.** 그 뒤의 코드가 조용히 사라져요. 줄 중간에는 `/* */`를 써 주세요. `node tests/syntax.js`가 이 실수를 잡아요.
2. 고친 뒤 테스트를 돌려 주세요. 브라우저 테스트(Playwright)는 AI 서버를 자동으로 끄거나 가짜 응답을 써서 무료 한도를 쓰지 않아요.
   ```bash
   node tests/syntax.js && node tests/ai-worker.mjs && node tests/flow-fixes.js && node tests/ai-chat.js && node tests/e2e-v5.js
   ```
   사파리(맥·아이폰)에서도 확인하려면 `node tests/safari-check.js`를 돌려요. 사파리와 같은 엔진(WebKit)으로 큰 화면, 전시 화면, 아이폰 크기에서 모든 화면을 열어 봐요.
3. 배포 전에 `sw.js`의 `CACHE` 버전 숫자를 하나 올려 주세요. 그래야 휴대폰에 새 버전이 바로 받아져요.
4. 제출 파일이 필요하면 `python3 tools/build-submission.py`를 돌려요.
5. AI가 대답하는 방식은 `ai-worker/worker.js`의 `FRAME_KO`(판단 원칙과 예시)와 `APP_GUIDE_KO`(앱 설명서)에서 바꿔요. 규칙을 한 줄씩 덧붙이기보다 원칙과 예시를 고치는 게 좋아요.
6. AI 대답을 바꿨다면 정답지 시험으로 점수를 비교해 주세요. 시험용 서버와 시험용 키를 써서 앱의 무료 한도는 쓰지 않아요.
   ```bash
   node tools/eval-flow.mjs
   ```

## 릴리스

```bash
tools/release.sh "바꾼 내용"          # 문법 점검 → sw.js 캐시 버전 +1 → B.html/B.zip → 커밋 → 푸시
tools/release.sh --full "바꾼 내용"   # 기능 테스트 전체까지
tools/release.sh --no-push "바꾼 내용" # 커밋까지만
```
